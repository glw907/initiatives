# ECXC rebuild

## Summary

This proposed initiative would rebuild ecxc.ski on the current cairn. It starts once `cairn-docs-standard` completes.

## Motivation

The site should run on the current engine and follow the docs standard, as the other cairn-family sites will.

## Goals

- Rebuild ecxc.ski on the current cairn.

## Non-goals

- The site's pre-announce gate, which its STATUS tracks on its own.
- Starting before `cairn-docs-standard` completes.

## Where the work lives

- `ecxc-ski`: the site.

## Records

- Requirements (organizational functions, 2026-10-29): `ecxc-ski/docs/specs/2026-10-29-ecxc-rebuild-requirements.md`.
  It supersedes the 2026-07-30 team-platform requirements where they disagree.
