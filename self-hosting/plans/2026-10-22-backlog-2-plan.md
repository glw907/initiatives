# Servers backlog, second batch: plan

## Brief

This plan builds the approved design `self-hosting/specs/2026-10-22-backlog-2-design.md`: twelve servers backlog items in one pass, on one servers branch, with one PR that comes back to Geoff through `conductor-servers`. The emergency screens go first, so they exist before the second operator's session on 2026-10-24. The planned path is 330 minutes. Nothing here needs Geoff before launch.

## Entry

## Standing answers

The design's table applies, plus these.

| Situation | Answer |
|---|---|
| Immich's queue call answers but no dump appears in 10 minutes on the live probe | Read the container's log for the job; if the queue name or body is wrong for v3.3.4, fix it from the log and rerun once. A second miss stops T2's live probe and is listed under `## Not checked`; the code still refuses a rebuild without a fresh dump. |
| A pair's files turn out to overlap | Run the two tasks in sequence and record it under `## Decisions`. |
| The disk comparison finds missing files on the drill | A finding: record the paths' count and first ten by id, fail the drill, and stop for the conductor. It means a backup is incomplete. |
| `restore-drill.sh` leaves a server behind | Delete it by its `drill-` name with `hcloud server delete`, which the drill's own rules cover, and record it. |

Stops: the path ceiling in the design (800 minutes), a backup that a drill shows incomplete, a cause the session cannot trace, a classifier denial of a live call, a secret only Geoff has.
