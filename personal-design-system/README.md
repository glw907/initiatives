# Personal design system

## Summary

This proposed initiative would give Geoff's own surfaces one visual language. Four pieces would join under it: Survey in `cairn-themes`, the 907.life theme in `907-life`, the approval queue app, and the Docs letterhead.

## Motivation

Each piece has its own tokens and its own taste decisions, and they are made again each time. One system would settle a decision once.

## Goals

- Name the shared tokens and components the four pieces would use.
- Keep one decision log, so a ruling about a color or a type size applies everywhere.

## Non-goals

- Restyling the cairn-family sites for clients. Those follow each site's own design.
- Starting before the approval queue's grouping work and the shared-standards effort land.

## Where the work lives

- `cairn-themes`: Survey.
- `907-life`: the 907.life theme.
- `approval-queue`: the app's interface.
- Google Docs: the Docs letterhead. It is a surface, not a repo.

## Records

- The deleted `personal-styles` repo defined a collection shape worth reusing: a style sheet, a decision log, and benchmark renders for each piece. A new collection, `personal-styles`, would follow that shape. The repo's history is not kept, so this note is its record.
