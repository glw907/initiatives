The nine directives, light and dark

Every block a post can use, in one post body. Survey's specimen styles only the alert, so the rest are new and drawn from Survey's parts: the paper-shade ground, the 1px edges, the dashed contour rule, and the benchmark triangle. Each grey tag names the block.

One conflict: Survey says reading text carries no icons, but cairn's vocabulary has an inline icon block. I've drawn it small and muted, in the text's color, so it reads as a glyph rather than decoration.
