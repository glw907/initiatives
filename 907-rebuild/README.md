# 907.life rebuild

## Summary

This proposed initiative would rebuild 907.life on the current cairn and re-skin it on Survey, including Survey's cairn layer (S2). It starts once `cairn-docs-standard` completes.

## Motivation

907.life runs on an earlier cairn. Rebuilding on the current engine brings the site onto the docs standard and the current theme work.

## Goals

- Rebuild the site on the current cairn.
- Re-skin it on Survey.
- Build Survey's cairn layer (S2).

## Non-goals

- The Survey core (S1). It stays the next action in `cairn-themes`.
- Starting before `cairn-docs-standard` completes.

## Where the work lives

- `907-life`: the site.
- `cairn-themes`: Survey, which supplies the theme. Its S1 is outside this record.
