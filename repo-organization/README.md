# Repo organization

## Summary

This initiative gives every initiative a record in this repo, moves past specs and plans to the repo that owns them, and retires repos and folders nobody uses.

## Motivation

Work that spans repos had no home, so its specs and plans piled up in `workstation`.

## Goals

- Hold one record per initiative here.

## Non-goals

- Grouping the approval queue by initiative.

## Where the work lives

- `initiatives`: the records and this pass's tools.
